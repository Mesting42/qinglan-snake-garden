# 青岚蛇园

一款桌面与移动浏览器都可游玩的连续转向贪吃蛇游戏。所有场景、蛇、果实、障碍和音效都由项目代码绘制或合成，不需要外部素材服务。

## 环境与启动

- Node.js 20.19+ 或 22.12+
- npm 10+

从干净副本安装依赖并启动开发服务器：

```bash
npm install
npm run dev
```

启动后打开 `http://localhost:5189/`。需要从同一局域网的手机打开时，使用开发服务器输出的局域网地址。若浏览器显示“localhost 拒绝建立连接”，先在本项目目录运行 `npm run dev`；终端进程需要保持运行。

生产构建与本地预览：

```bash
npm run build
npm run preview
```

预览同样使用 5189 端口；运行生产预览前先停止开发服务器。

运行自动化逻辑测试：

```bash
npm test
```

## 操作

**电脑**：只用 WASD 或方向键控制蛇头转向。按住 Shift 加速，Esc 或 P 暂停。鼠标只用于点击菜单和按钮，不控制蛇。

**手机和平板**：左侧虚拟摇杆转向，右侧大按钮按住加速。支持同时拖动摇杆和按住加速；横竖屏均可操作。

手机推荐竖屏：花园的上下转弯空间更充足，两个触控区位于场地外。横屏也可游玩，场地两侧会预留操作空间。旋转或缩放不会重新开始本局；浏览器取消触控时，松开手指后重新拖动摇杆即可。加速按钮下方的小条显示剩余能量。

浏览器适配复测的尺寸、结果与截图见 [TESTING.md](./TESTING.md)。

暂停时游戏计时与移动都会停止。转向为连续角度变化，蛇身沿经过的曲线跟随。巡游关卡加入按固定花纹路线移动的其他蛇，路线可见，进入警戒范围后会主动追击，头顶感叹标记提示危险；被它们碰到会立即判负，护叶也不能抵挡。晨光温室、溪畔花园、月色植物园逐步增加数量。设置可调整移动速度、转向灵敏度、音乐、音效、画质和动态效果。

## 内容

- 首次游玩的可跳过引导关
- 晨光温室、溪畔花园、月色植物园共 12 个关卡
- 无尽拾光与按本地日期固定路线的今日花径
- 星级结算、花纹解锁、音效合成与本地进度保存
